# PORTFOLIO

Prototype et ressources pour le portfolio de Yvan Leugoue.

Contenu ajouté par l'assistant:

- `design-spec.md` — fichier de spécifications de design
- `figma-wireframes/` — trois wireframes SVG (desktop/tablet/mobile) à importer dans Figma
- `prototype/` — prototype HTML/CSS (index + style)

Comment utiliser:
- Ouvre `PORTFOLIO/prototype/index.html` dans un navigateur pour voir la version prototype HTML.
- Dans Figma, crée un nouveau fichier et importe les SVG de `figma-wireframes` pour démarrer le design.

Si tu veux que je pousse ces changements sur GitHub, indique le nom du repo distant et confirme si `gh` est installé/configuré sur ta machine, ou fournis un PAT/SSH configuration.
